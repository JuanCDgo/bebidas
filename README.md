# 🍺 Maldito Flanders · Delivery de Bebidas, Promos & Kiosco

Micro-aplicación web para delivery de bebidas en moto, previas, vinotecas y kiosco nocturno.

## Características Principales
- 🔥 **336 Productos y Promos Reales Precargados** en 16 categorías con sub-filtros de Promos (*Fernet, Vodka/Smirnoff/Skyy, Gin, Ron/Whisky, Aperitivos, Vino*).
- 🛵 **Freno Automático de Compra Mínima ($7.000) y Envío ($1.500)** configurables.
- 🛵 **Panel de Despacho y Rendición de Caja para 2 Cadetes (`Moto 1` y `Moto 2`)**.
- 📋 **Generador en 1 Toque de Lista de Precios Completa para WhatsApp** con marca automática de `[sin stock]`.
- ⭐ **Club de Fidelidad con piso mínimo de compra ($15.000)** y Pase Digital Público (`?pass=ID`).
- 📷 **Cobro QR Mostrador con Doble Motor** (`QRCode.js` + `QuickChart.io`).
